# Awaitonal 0.1.0

First packaged release of a local musical notification engine for coding agents.

- Four deterministic gestures for done, caveats, needs-you, and rejected.
- Audition/rendering CLI, editable TOML palette, bounded local service, and notification-only Claude Code hooks.
- Rules classifier and optional real offline MiniLM embedding backend, with separate evaluation fixtures.
- Source, wheel, audition WAV, checksums, tests, and exact setup/removal instructions.

Local Apple Silicon validation: 206 core tests passed; two model-dependent checks
were skipped in the minimal environment. With optional dependencies and locally
downloaded weights, all 208 tests passed. The macOS playback command succeeded.
The rules baseline scored 30/30 on the included fixtures. The experimental semantic
classifier scored 13/30, so rules remains the default.

No human listening/reference comparison was performed, and hooks have not been
fired inside a real Claude conversation. No reference WAV was supplied.

See README.md and VALIDATION.md for commands, exact results, and limitations.
Installation does not modify Claude settings or install a background service.
