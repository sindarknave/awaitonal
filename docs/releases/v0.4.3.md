# v0.4.3 — mute and unmute skills

Use `/awaitonal:mute` and `/awaitonal:unmute` in Claude Code to silence or resume
Awaitonal notifications. The resident service and model stay loaded, so unmuting
does not require a cold start. `/awaitonal:status` reports the mute state.

The matching CLI commands are `awaitonal service mute` and
`awaitonal service unmute`. They use authenticated, instance-guarded controls;
the plugin also checks that the service belongs to its own runtime.

Mute applies to all sessions sharing the service until unmuted or restarted.
Queued notifications and results still being classified are discarded rather
than replayed after unmute. A cue already starting or playing may finish.
Unmute resumes future notifications and does not play a test sound. Diagnostic
`--silent` mode remains silent.

Update the plugin, restart Claude Code, and rerun `/awaitonal:setup` to install
the new runtime before using these commands. Neither skill installs packages,
starts a stopped service, or changes system volume as a fallback.
