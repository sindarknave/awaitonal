# v0.7.0 — phrases that reflect the turn

Routine answers and completed changes now have four arrangements each. The
service uses measured elapsed turn time to choose a lighter or fuller group,
then alternates phrases within that group for each session and outcome. This
reduces repetition while giving the variation a consistent meaning.

- Under two minutes: lighter arrangements.
- Two minutes or more: fuller arrangements.
- Missing or uncertain timing: the original cue.
- Session instruments stay stable; attention cues keep their existing phrases.

The cutoff is configurable with `variation_full_after_seconds`. Set
`gesture_variations = false` to keep the originals. Timing is elapsed work and
waiting, not model reasoning duration. The optional extended long-turn endings
remain a separate setting. No additional model call or dependency is needed.

Download and extract `awaitonal-0.7.0-listening-preview.zip`, then open
`index.html` for all four phrases across six instruments, an eight-turn
comparison with selection explanations, and missing-timing examples. Audio
starts only when you press Play. See the
[variation guide](https://github.com/sindarknave/awaitonal/blob/v0.7.0/docs/gesture-variations.md)
for settings and custom palettes.

## Classifier fixes and evidence

Rules now recognize more concrete assessments, artifact updates, publication
reports, ongoing-work promises, and blocked-work reports. A prepared draft
followed by a direct request to send it is treated as authorization. Tests cover
negation, historical references, optional offers, and resolved requests.

The 16 supplied regression cases improve from 2/16 to 16/16 correct musical
gestures. Overall agreement on the separate public sample remains unchanged:
66/92 outcomes and 41/92 gestures. Those public labels were produced by AI before
seeing predictions; 25 have recorded ambiguity, and none are required handoffs.
These results support the specific fixes, not a general accuracy improvement.
See the [evaluation report](https://github.com/sindarknave/awaitonal/blob/v0.7.0/docs/classification-v061-evaluation.md)
for the method, limitations, and remaining errors. Raw conversations are excluded.

## Update

For the Claude plugin:

```sh
claude plugin marketplace update awaitonal
claude plugin update awaitonal@awaitonal
```

Restart Claude Code and run `/awaitonal:setup` to upgrade the shared Python
runtime. For Codex, update the plugin and rerun its setup skill. For Pi, install
the new tag, reload, and run `/awaitonal-setup`:

```sh
pi install git:github.com/sindarknave/awaitonal@v0.7.0
```

Updating plugin files alone does not upgrade a running service. Setup and service
restart are explicit local actions; this release does not change your installation.

listening preview, and SHA-256 checksums. Audio playback currently targets macOS.
