# v0.4.0 — clearer outcomes and optional elapsed-time voicing

Replies that explain errors or offer optional follow-up work no longer default to
an unresolved-work sound. Unrecognized prose keeps an explicit `unknown` outcome
and a restrained answer cue; it does not claim the task succeeded.

- Recognize currently delivered artifact links, opened PRs, and posted reviews,
  while excluding citations, historical actions, browser inspection, and URL query
  text. Explicit unfinished work and verification gaps still receive caveats.
- Add a firm `verdict` variant for completed assessments, an expectant
  `authorization` cue for prepared outward work awaiting approval, and a quiet
  `in-flight` cue for reported continuing work. In-flight is silent by default.
- Corroborate ongoing work using bounded Stop background-task/cron counts. No task
  descriptions, commands, scheduled prompts, or tool results are retained.
- Add optional longer-turn voicing at matched energy and unchanged duration. It
  measures elapsed waiting, not model thinking. Missing or ambiguous timing keeps
  normal playback; handoffs and failure cues are unchanged.
- Preserve pending results when silent activity arrives, avoid a duplicate Stop
  poisoning later turn timing, and reduce repeated question/Stop notifications.
- Add 115 synthetic development contrasts and independent activity/assessment/
  handoff evaluation labels, plus false-caveat, missed-handoff, and unknown metrics.

All eleven existing cues are sample-identical with long-turn voicing disabled.
The original `review` gesture identifier is retained and described as feedback
requested. The optional semantic backend shares deterministic routing and uses
neutral uncertainty on abstention; rules remains the default.

Optional service configuration:

```toml
[notifications]
min_turn_seconds = 30
long_turn_seconds = 120
notify_in_flight = false
```

Both thresholds default to zero. Matched timing requires Claude hook prompt IDs
(2.1.196+); older clients retain ordinary playback. Audition the longer variant
with `awaitonal play verdict --long-turn`.

See [validation](../../VALIDATION.md) for test results, authored-fixture limits,
offline-model checks, and measured latency. The palette has not undergone a blind
listening study, and no cue independently verifies an agent's work.
