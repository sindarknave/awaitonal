# v0.5.0 — rotating session voices

Parallel sessions now have a rotating set of six instruments: marimba, powersaw
brass, harp, clarinet, crystal key, and flute. Each session keeps its instrument
when it returns. New sessions prefer unused voices; after all six are occupied,
the least-used voice is reused in rotation order. Assignments survive mute/unmute
and expire after an hour without an event. Restarting the service resets them.

The voices have soft attacks, short decays, and enough body to carry the existing
outcome phrases. They share tuning and harmonic overtones; brass adds only slight
detuning. The original pitches and note onset times remain, with shorter note
tails and trimmed trailing silence. Long turns keep their extra rising attacks.
The original `default`, `wood`, `glass`, and `round` voices remain available.

## Listen and enable

```sh
awaitonal ensemble-demo --mode rotation --out rotation.wav
awaitonal play review --voice powersaw --out review.wav
```

Live session voices are opt-in through the service's palette file:

```toml
[notifications]
session_voices = true
voice_cycle = ["marimba", "powersaw", "harp", "clarinet", "crystal", "flute"]
```

Use any nonempty subset/order of supported voices. Restart the service after
changing its configuration. See [session voices](../session-voices.md) for
standalone and Claude plugin commands, the complete example, and listening modes.

Live playback stays serial, with existing attention priority. When another
session is waiting, routine results omit optional long-turn extensions. Overlap
mode is only a composed listening comparison. Six voices cannot uniquely
identify more than six simultaneous sessions; the registry remains bounded to
128 session IDs, with conservative default-voice fallback at that limit.

## Update

```sh
claude plugin marketplace update awaitonal
claude plugin update awaitonal@awaitonal
```

Restart Claude Code, then run `/awaitonal:setup` to upgrade the stable Python
runtime. This publication does not change an already-running installation.
See [the plugin guide](../plugin.md) for new installations and migrations.

## Validation

The full local core suite passes 1,269 tests, with two optional-model skips.
Checks cover voice rotation, stable returning sessions, idle expiry, bounded
overflow, custom cycles, queue/mute behavior, shortened envelopes, pitch, level,
headroom, and the CLI listening modes. See [observed validation](../../VALIDATION.md)
for package integration evidence and limits. No new model or dependency is needed.

Downloads include the Python wheel, source archive with the Claude plugin, a
six-voice done/review comparison, a new/returning-session rotation demo, and
SHA-256 checksums. This remains a prerelease, consistent with previous versions.
