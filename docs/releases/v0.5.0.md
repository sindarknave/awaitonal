# v0.5.0 — session voice prototype

Three instruments distinguish parallel sessions while retaining the existing
outcome gestures: a wooden pluck, a soft glass bell, and a rounded electric piano.
Use `awaitonal play review --voice glass` to audition one, or
`awaitonal ensemble-demo --out voices.wav` for the nine voice/outcome examples.
Serial and overlap demo modes compare a three-notification sequence; overlap is
only a listening experiment.

Live session voices are opt-in through `[notifications] session_voices = true`.
The first three active session IDs get distinct instruments, with bounded,
in-memory assignments stable until an hour of inactivity or a service restart.
Extra sessions use the original instrument. The service retains serial playback;
queued competition from another session selects normal-length routine endings
instead of extended long-turn endings. Existing attention priority still applies.

The original default audio, classifier, hook format, and warm resident service
remain. Named voices preserve pitches and event timing, match RMS level, and
respect the peak limit. See [listening and setup](../session-voices.md) for scope,
commands, and the perceptual checks still needed.
