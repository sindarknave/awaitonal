# Awaitonal 0.3.0

Awaitonal now ships as a Claude Code plugin and marketplace in this repository,
while retaining its resident local service. Install the plugin, then run
`/awaitonal:setup` to explicitly install or update the stable Python runtime and
start notifications. Hook execution never installs dependencies.

- `StopFailure` produces a distinct infrastructure-failure cue. Authentication,
  billing, and account problems use the existing required-action cue. Only a
  normalized error code is forwarded; rendered errors and error details are discarded.
- Service start/stop/status uses an authenticated local control exchange, with
  instance and executable ownership checks. macOS login startup is optional.
- `doctor` checks dependencies, hooks, duplicate registrations, socket trust,
  service compatibility, and playback availability. Audio testing is explicit.
- Standalone init/uninstall previews changes, backs up settings, and tracks exact
  owned hooks. Plugin migration shares this logic and preserves unrelated settings.
- Configurable short-turn suppression defaults off. It applies only to routine
  completed results with reliable timing; review, caveats, handoffs, refusals, and
  failures remain eligible for playback.

Before upgrading from 0.2, stop its foreground service with Ctrl-C. It predates
the authenticated control protocol and cannot be safely stopped by the new CLI.
Existing hand-pasted hooks require explicit exact-executable migration; see
[plugin setup](../plugin.md). After later plugin updates, rerun setup to upgrade
the runtime outside Claude's disposable cache.

Timing suppression requires matching prompt IDs, absent in Claude Code 2.1.158.
Older versions continue to play notifications normally. The optional semantic
model still uses four text-outcome classes; structured failures bypass it.

The event and classification schema now includes failure metadata and the
`failed` outcome/control. Existing palette overrides inherit the new cue.
See [validation](../../VALIDATION.md) for what was exercised and its limits.
